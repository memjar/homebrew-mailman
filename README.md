# homebrew-mailman

Homebrew tap for [mailman](https://github.com/memjar/mailman), the AXE email CLI.

```sh
brew tap memjar/mailman https://github.com/memjar/homebrew-mailman
brew install mailman
```

Installs the official per-platform release tarballs (macOS arm64/Intel, Linux arm64/x86_64)
from the GitHub releases, checksums pinned in the formula.
